# Premium HDPE Piping & Solutions Landing Page

A high-performance, pixel-perfect landing page designed for an HDPE (High-Density Polyethylene) pipe manufacturer. This project combines premium aesthetics with interactive functionality to provide a seamless user experience.

## 🚀 Key Features

- **Interactive Product Gallery**: A dynamic hero section with a thumbnail-driven image switcher for high-quality product visualization.
- **Infinite Brand Loop**: A functional "Trusted by" section featuring a smooth, infinite scrolling logo carousel.
- **Applications Slider**: A responsive slider showcasing various industrial use-cases for HDPE solutions.
- **Interactive Process Tabs**: A structured walkthrough of the manufacturing process using tabbed navigation and synchronized imagery.
- **Auto-Sliding Testimonials**: A functional social proof section with automatic transitions for client success stories.
- **Comprehensive Specs**: A clean, detailed technical specifications table for professional data presentation.

## 🛠️ Tech Stack

- **HTML5**: Semantic markup for better SEO and accessibility.
- **CSS3**: Custom design system using variables, Flexbox for layout, and Keyframe animations for smooth interactions.
- **Vanilla JavaScript**: Lightweight, dependency-free logic for sliders, accordions, and tab interactions.

## 🎨 Design Philosophy

The project follows a **Premium Industrial Aesthetic**:
- **Modern Typography**: Using clean, sans-serif fonts for high readability.
- **Professional Palette**: A curated mix of deep blues, sleek grays, and subtle gradients.
- **High-Quality Imagery**: Custom-generated industrial visuals that elevate the brand's professional appeal.
- **Micro-animations**: Subtle hover effects and transitions that make the interface feel alive.
